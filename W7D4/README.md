# Phantoms AI – Week 7
## Day 4: RAG Experiments

## 1. مقدمة

في اليوم الرابع من Week 7، قمنا بإجراء خمس تجارب لدراسة العوامل التي تؤثر على أداء نظام RAG (Retrieval-Augmented Generation).

كان الهدف هو فهم كيفية تحسين استرجاع المعلومات (Retrieval)، وتحسين جودة الإجابات التي يقدمها نموذج اللغة (LLM)، وتقليل احتمالية اختراع معلومات غير موجودة في المستندات (Hallucination).

---

## 2. التجربة الأولى: Embedding Models Comparison

**الهدف:** دراسة تأثير تغيير نموذج Embedding على نتائج استرجاع المعلومات.

تمت المقارنة بين:
- ChromaDB Default Embedding Model.
- paraphrase-MiniLM-L3-v2.

**النتائج:**

النموذج الأصلي استرجع:
- True/False Questions.
- Multiple Choice Questions.
- Database Concepts.

أما النموذج الثاني فاسترجع:
- Multiple Choice Questions.
- Database Concepts.
- True/False Questions.

**ملاحظة مهمة:**

تم اكتشاف مشكلة في منهجية المقارنة؛ حيث تم استخدام Query Embedding من نموذج مختلف مع Document Embeddings القديمة.

لذلك يجب إعادة إنشاء Embeddings للمستندات باستخدام النموذج الثاني قبل اعتبار المقارنة عادلة.

## 3. التجربة الثانية: Chunk Size Comparison

**الهدف:** دراسة تأثير حجم تقسيم المستندات على جودة الاسترجاع.

تمت مقارنة ثلاثة أحجام:

| النوع | عدد Chunks |
|---|---:|
| Small | 64 |
| Medium | 28 |
| Large | 15 |

**النتائج:**

- Small: استرجع السؤال المطلوب في النتيجة الأولى، وحقق Distance بقيمة 0.866.
- Medium: استرجع معلومات مرتبطة بالسؤال، وحقق Distance بقيمة 0.892.
- Large: استرجع السؤال المطلوب في النتيجة الثانية، وحقق Distance بقيمة 1.060.

**الاستنتاج:**

حقق Small أفضل ترتيب لاسترجاع المعلومة المباشرة في الاختبار الحالي.

كما لاحظنا أن زيادة حجم Chunk تقلل عدد الأجزاء الناتجة عن تقسيم المستند.

## 4. التجربة الثالثة: Top-K Comparison

**الهدف:** دراسة تأثير عدد Chunks المسترجعة على جودة المعلومات المتاحة للنظام.

تمت مقارنة:
- Top-1
- Top-3
- Top-5

**النتائج:**

Top-1:
- استرجع نتيجة واحدة.
- Distance = 1.060.

Top-3:
- استرجع ثلاث نتائج.
- ظهرت معلومات السؤال المطلوب في النتيجة الثانية.
- Distances: 1.060, 1.182, 1.330.

Top-5:
- استرجع خمس نتائج.
- أضاف معلومات أخرى متعلقة بقواعد البيانات.
- آخر نتيجتين كانتا بمسافتي 1.359 و1.375.

**الاستنتاج:**

زيادة Top-K توفر سياقًا ومعلومات إضافية للنظام، لكنها قد تضيف معلومات أقل ارتباطًا بالسؤال.

كما أن ترتيب النتائج الثلاث الأولى ظل ثابتًا في الاختبار.

## 5. التجربة الرابعة: Prompt Engineering

**الهدف:** دراسة تأثير System Prompt على إجابات نموذج اللغة وتقليل Hallucination.

تمت مقارنة ثلاثة أنواع من التعليمات:

1. Without Restrictions:
   الإجابة دون قيود إضافية.

2. Context Only:
   الإجابة باستخدام المعلومات الموجودة في Context فقط.

3. Context Only + Abstention:
   الإجابة باستخدام Context فقط، مع الامتناع عن التخمين عند عدم وجود الإجابة.

**الاستنتاج المستهدف:**

دراسة تأثير التعليمات المختلفة على التزام النموذج بالسياق وتقليل اختراع المعلومات.

---

## 6. التجربة الخامسة: Metadata Filtering

**الهدف:** دراسة تأثير استخدام Metadata Filtering على نتائج الاسترجاع.

تمت المقارنة بين:

A - Without Metadata Filtering:
- عدد النتائج: 3.
- ظهرت نتائج من الصفحات 3 و1 و8.

B - With Metadata Filtering:
- استخدمنا:
  `where={"page": 1}`
- عدد النتائج: 2.
- النتائج المسترجعة كانت من الصفحة 1 فقط.

**الاستنتاج:**

ساعد Metadata Filtering على تحديد نطاق البحث داخل صفحة معينة من المستند، وقلل عدد النتائج المسترجعة من 3 إلى 2 في الاختبار الحالي.
